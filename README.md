# Java Picine - School 42 Java Projects

This repository contains a collection of Java projects completed as part of the School 42 curriculum. Each module focuses on different aspects of Java programming, from basic concepts to advanced topics like Spring Framework and networking.

## 📚 Project Structure

The project is organized into modules, each containing multiple exercises:

- **module-00**: Basic Java fundamentals and syntax
- **module-01**: Object-oriented programming concepts
- **module-02**: File handling and command-line applications
- **module-03**: Multithreading and concurrency
- **module-04**: Image processing and character art
- **module-05**: Database connectivity and SQL
- **module-06**: Testing frameworks and data processing
- **module-07**: Reflection, annotations, and ORM
- **module-08**: Spring Framework basics
- **module-09**: Network programming and chat applications

## 🚀 Getting Started

### Prerequisites

- Java 8 or higher
- Maven (for modules that use it)
- Git

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd java-picine
```

2. Navigate to any specific module:
```bash
cd module-XX/exXX
```

3. For Maven projects, compile and run:
```bash
mvn clean compile
mvn exec:java -Dexec.mainClass="fr.school42.Program"
```

For simple Java projects:
```bash
javac *.java
java Program
```
