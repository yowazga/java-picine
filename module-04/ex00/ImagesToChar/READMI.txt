# README.txt

Project: Image to Character Converter
This program converts a black-and-white BMP image into a character-based representation in the console. It accepts command-line arguments to specify the characters for white and black pixels, as well as the path to the image file.

# How to Compile and Run the Program

1- Navigate to the Project Directory:
Open a terminal and navigate to the root directory of the project (ImagesToChar).
2- Compile the Program:
Run the following command to compile the Java source files:
		javac -d target ./src/java/fr/school42/**/*.java
3- Run the Program:
Use the following command to run the program:
		java -cp target fr.school42.printer.app.Program <image_path> <black_char> <white_char>
Example: java -cp target fr.school42.printer.app.Program /path/to/image.bmp 0 .
